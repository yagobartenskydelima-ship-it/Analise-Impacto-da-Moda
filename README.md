# 🌎 Impactos Ambientais do Descarte de Roupas

## 📌 Sobre o projeto

Este projeto tem como objetivo analisar os impactos ambientais relacionados à produção, reutilização, circulação e descarte de roupas.

A pesquisa busca compreender como o mercado de roupas de segunda mão, incluindo brechós, doações e exportações de roupas usadas, pode contribuir para o prolongamento da vida útil das peças e quais problemas ambientais podem surgir quando essas roupas não conseguem ser reutilizadas ou recicladas.

## 🎯 Problemática

**Como o crescimento da produção e circulação de roupas usadas influencia a geração de resíduos têxteis e quais oportunidades de reutilização, reciclagem e economia circular podem ser identificadas por meio da análise de dados?**

## 🔎 Objetivo

Utilizar dados públicos para analisar:

* a produção e circulação de roupas;
* o comércio de roupas usadas;
* os principais países de destino;
* a reutilização de peças;
* a geração de resíduos têxteis;
* os possíveis impactos ambientais;
* as oportunidades de economia circular.

## 📊 Metodologia

O projeto será desenvolvido em diferentes etapas:

1. Levantamento de fontes de dados públicas;
2. Coleta e organização dos dados;
3. Limpeza e tratamento dos dados;
4. Análise exploratória dos dados (EDA);
5. Utilização de Python, SQL e PySpark;
6. Identificação dos principais padrões e insights;
7. Criação de visualizações;
8. Desenvolvimento de um dashboard no Looker Studio.
